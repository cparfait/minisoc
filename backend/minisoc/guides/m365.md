# Microsoft 365 / Entra ID : journal d'audit unifié

Le Mini-SOC lit le **journal d'audit unifié** de Microsoft 365 : connexions Entra ID (réussies, échouées, MFA),
rôles d'administration, consentements d'applications, règles de transfert de messagerie. **Aucune licence Entra ID
P1 n'est nécessaire** (contrairement à l'API des journaux de connexion). Délai de mise à disposition par Microsoft :
de 30 minutes à quelques heures.

Ce qui est détecté :
- connexion depuis l'étranger (UC-34) ;
- voyage impossible (UC-35) ;
- pulvérisation de mots de passe (UC-36) ;
- échecs répétés depuis l'étranger (UC-37) ;
- fatigue MFA (UC-38) ;
- transfert de messagerie vers l'extérieur (UC-39) ;
- rôle d'administration attribué ou MFA désactivée (UC-40) ;
- consentement à une application (UC-41).

## Prérequis
- Un compte **Administrateur général** (ou Administrateur d'application + Administrateur de rôle privilégié pour
  le consentement).
- Accès HTTPS sortant du Mini-SOC vers `login.microsoftonline.com` et `manage.office.com`.
- La base **GeoIP** active (intégration Géolocalisation) pour connaître le pays des connexions.

## Étapes
1. Centre d'administration **Entra** (entra.microsoft.com) › *Identité › Applications › Inscriptions
   d'applications* › **Nouvelle inscription** : nom « Mini-SOC », *Comptes dans cet annuaire organisationnel
   uniquement*, pas d'URI de redirection.
2. *Autorisations des API* › **Ajouter une autorisation** › onglet *API utilisées par mon organisation* ›
   **Office 365 Management APIs** › *Autorisations d'application* › cocher **ActivityFeed.Read** › Ajouter.
   Puis **Accorder un consentement d'administrateur** : la colonne État doit indiquer « Accordé pour … ».
3. *Certificats et secrets* › **Nouveau secret client** (description « Mini-SOC », 24 mois au plus) › Ajouter.
   Une ligne apparaît avec deux colonnes : copier **tout de suite** la colonne **Valeur**. Elle est masquée dès
   qu'on quitte la page (il faudrait alors créer un autre secret). Noter la date d'expiration dans votre agenda.
4. Vérifier que l'audit est actif : portail **Microsoft Purview** › *Audit* (ou *Solutions › Audit*). Une page de
   recherche sans bannière : actif, rien à faire. Une bannière « Commencer à enregistrer l'activité des
   utilisateurs et des administrateurs » : cliquer dessus.
5. Dans cette fenêtre (onglet Configuration), recopier :

| Champ du Mini-SOC | Où le trouver dans Entra | Format |
| --- | --- | --- |
| Identifiant du tenant (ID de l'annuaire) | application Mini-SOC › *Vue d'ensemble* › **ID de l'annuaire (locataire)** | `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` |
| Identifiant de l'application (client) | même page › **ID d'application (client)** | `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` |
| Secret client | *Certificats et secrets* › colonne **Valeur** (étape 3) | une quarantaine de caractères, avec souvent `~` `.` `_` |

   Ne pas confondre la **Valeur** du secret avec la colonne **ID de secret** à côté, au format
   `xxxxxxxx-xxxx-…` comme les deux identifiants : c'est l'erreur « AADSTS7000215 ». Laisser « Règles de transfert
   de messagerie » coché. **Enregistrer**, puis **Tester** : le test active les abonnements aux journaux.
6. Paramètres › Détection : **pays habituels** (ex. `FR`), utilisés par les règles « depuis l'étranger ».

## Vérifier
- Le test indique « Connexion réussie, abonnements AzureActiveDirectory : enabled, Exchange : enabled ».
- Après 30 min à quelques heures : Mini-SOC › **Événements**, source Microsoft 365 : connexions des agents.

## Dépannage
- **« AADSTS7000215 : Invalid client secret provided »** : la valeur collée est l'**ID de secret** au lieu de sa
  **Valeur**, ou le secret a expiré. La Valeur n'étant plus lisible, créer un nouveau secret (étape 3), coller sa
  Valeur, puis supprimer l'ancien.
- **« AADSTS700016 : Application … was not found »** : identifiant de l'application ou du tenant inversé ou mal
  copié.
- **« accès refusé (HTTP 401/403) »** : permission ActivityFeed.Read absente ou consentement administrateur non
  accordé.
- **Abonnements créés mais aucune donnée** : audit pas encore actif (étape 5) ; le premier démarrage de l'audit
  peut prendre jusqu'à 24 h.
- **Alertes « depuis l'étranger » injustifiées** : ajouter le pays dans les pays habituels, ou créer une exception
  pour l'utilisateur concerné depuis l'alerte.
