# Rançongiciel suspecté

Urgence absolue : chaque minute compte.

## Agir immédiatement
1. Isoler le poste concerné (EDR) ; à défaut, débrancher son câble réseau. Ne pas l'éteindre.
2. Désactiver le compte utilisateur concerné.
3. Vérifier les partages réseau accessibles par ce compte (fichiers renommés, notes de rançon).
4. Protéger les sauvegardes : vérifier qu'elles sont hors ligne ou immuables.

## Prévenir
- Direction, DPO (violation de données possible : notification CNIL sous 72 h).
- Prestataire de réponse à incident (label PRIS) et CERT-FR.
